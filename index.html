WASI Snapshot Preview 1 in Browser

The Nizam compiler generates native WebAssembly targetting wasm32-unknown-wasi. The in-browser execution engine shims the POSIX-compatible system call layer:

  • fd_write(fd, iovs, len, nwritten): Intercepts stdout (fd 1) and stderr (fd 2), streaming UTF-8 bytes into the reactive terminal.
  • args_get / args_sizes_get: Supplies command line arguments directly into 32-bit linear memory.
  • clock_time_get(id, prec, time_ptr): Connects to high-precision performance.now().
  • random_get(buf, len): Cryptographically secure random bytes via browser crypto.getRandomValues.
  • proc_exit(code): Captures exit codes safely without crashing the tab.
